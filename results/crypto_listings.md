# Листинги: где амплитуда

Событие — **первая минута торгов** нового спот-символа Binance. Точка отсчёта взята из самого архива: первый бар символа и есть момент открытия торгов, объявление не нужно (в фиде объявлений Binance `publishDate` приходит `None`).

Вход: **открытие второго бара** — через минуту после начала торгов, когда аукцион открытия уже прошёл. Первый бар не торгуется: у 1INCH он открылся по 0.20 при максимуме 2.90 в ту же минуту, то есть `open` первого бара — номинальный принт. Сам аукцион показан отдельно: медиана +18.14 %, среднее +405.42 % — это недостижимый потолок.

Издержки 14 бп, одна нога, только лонг — занимать токен, который только что открылся, негде.

`late` — вход через 15 мин после открытия: задержка, которую проект измерил на своём новостном рекордере (p50 15.9 мин). Разница между двумя блоками — цена того, что вход не мгновенный.
