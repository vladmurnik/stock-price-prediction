# S1 — качество классификации сентимента: вырожден ли признак

**STATUS: DONE. Классификатор не вырожден, и главная механическая гипотеза «направление задаёт
название компании» убита измерением. Остаётся более скучная причина: у 22 % торгуемых событий
|score| < 0.05, и знак там — монетка.**

Все числа воспроизведены `ops/audit_measure.py` и `ops/audit_perturb.py` на артефактах
`data/processed/article_sentiment_{finbert,openjev,lexicon}.parquet` (124 571 строка, 38 тикеров),
`reports/calibration/*.json` и `data/processed/intraday_gdelt_events.parquet`.

## 1. Распределения: три бэкенда, один корпус

| | FinBERT | open-jev | lexicon |
|---|---|---|---|
| neutral | **51.0 %** | 9.8 % | 38.1 % |
| very positive | 19.0 % | **45.5 %** | 1.1 % |
| very negative | 17.4 % | 6.9 % | 0.1 % |
| positive | 8.2 % | 25.3 % | 43.4 % |
| negative | 4.4 % | 12.5 % | 17.3 % |
| mean `score_5` | +0.018 | **+0.248** | +0.051 |
| sd `score_5` | 0.415 | 0.353 | 0.140 |
| доля \|p_pos − p_neg\| < 0.05 | **40.0 %** | 1.9 % | **38.1 %** |
| доля < 0.10 | 48.0 % | 3.9 % | 38.1 % |
| доля < 0.02 | 27.2 % | 0.7 % | 38.1 % |

Три вывода, каждый виден прямо в таблице:

1. **FinBERT даёт двугорбое распределение**: 36.4 % статей попадают в крайние классы, 51 % — в
   neutral, а между ними почти ничего. Для заголовков это означает «модель уверена или молчит»,
   без промежуточных оценок.
2. **open-jev смещён**: средний `score_5` +0.248, 45.5 % «very positive», neutral всего 9.8 %.
   Это не свойство новостей, это свойство модели: тот же корпус FinBERT называет нейтральным в
   пяти случаях из десяти. Доля \|d\| < 0.10 всего 3.9 % — мёртвой зоны практически нет, любая
   статья получает направление.
3. **lexicon — это 38.1 % точных нулей**: доли < 0.02, < 0.05 и < 0.10 совпадают до четвёртого
   знака, потому что `p_pos − p_neg` ровно ноль. Словарь не видит идиом и отрицаний, зато
   уверенно молчит на большинстве заголовков.

## 2. Калибровка: что 0.8862 говорит и чего не говорит

| метрика | FinBERT | open-jev | lexicon |
|---|---|---|---|
| n_eval | 210 | **25** | 210 |
| support (neg/neu/pos) | 34 / 153 / 23 | 5 / 17 / 3 | 34 / 153 / 23 |
| accuracy | 0.9238 | 0.5600 | 0.4000 |
| **macro-F1** | **0.8862** | 0.6080 | 0.3318 |
| accuracy по 5 классам (`label_5`) | **0.5190** | 0.1600 | 0.2286 |
| ECE | 0.0401 | **0.2198** | 0.2566 |
| temperature | 0.7041 | 0.8774 | 1.9868 |

`macro_f1 = 0.8862` получен на 210 размеченных **предложениях** Financial PhraseBank, из которых
153 (72.9 %) — neutral. Базовая линия «всегда neutral» даёт на этом наборе accuracy 0.729 и
macro-F1 ≈ 0.281, то есть FinBERT действительно выше baseline — но положительный класс содержит
**23 примера**, и точность на нём 0.8235 (±0.08 при таком n).

Три причины, по которым это число не переносится на заголовки:

1. **Домен текста другой.** PhraseBank — грамматические предложения с явным глаголом и
   направлением («Operating profit rose 4 %»). Заголовок — именная группа без глагола, часто без
   направления вообще («Apple Said to Plan Bond Sale»). Классификатор, калиброванный на первом,
   на втором выдаёт уверенность, которая ничем не обеспечена.
2. **Распределение классов другое.** На PhraseBank neutral 72.9 %, на заголовках FinBERT называет
   нейтральными 51.0 %, а крайними — 36.4 %. Модель систематически увереннее на входе, которого
   не видела при калибровке. ECE 0.0401 измерен на том же сдвинутом распределении предложений.
3. **Пять классов не работают.** `label_5_accuracy = 0.519` — модель путает positive и
   very positive примерно в половине случаев. Для направления (`p_pos − p_neg`) это не важно, но
   любое утверждение вида «модель различает силу тона» ложно.

**open-jev непригоден для этого корпуса**: калибровка на 25 примерах, ECE 0.220, `label_5_accuracy`
0.16. **lexicon** тоже: macro-F1 0.332, ECE 0.257, 38 % нулей. Дневная ветка это уже показала
абляцией A3 (0.0112 против 0.0134 у FinBERT) и A8 (0.0076 против 0.0156).

## 3. Perturbation-тест: направление не задаётся именем компании

200 заголовков из корпуса, в которых присутствует название компании (выборка с seed 42 из
33 973 подходящих), прогонялись дважды: как есть и с заменой имени на «the company».

```
orig: The 3 Electric Vehicle Companies Tesla Should Fear Most
pert: The 3 Electric Vehicle Companies the company Should Fear Most
```

| метрика | значение |
|---|---|
| флипов знака `p_pos − p_neg` | **12 / 200 = 6.0 %** |
| корреляция `d_orig` и `d_pert` | **0.9747** |
| флипов среди уверенных (\|d\| ≥ 0.2, n = 93) | **0.0 %** |
| mean \|d\| до / после | 0.3669 / 0.3561 |

Гипотеза «модель реагирует на бренд, а не на содержание» **опровергнута**: убирание имени меняет
знак в одном случае из шестнадцати, а среди уверенных предсказаний не меняет никогда. Это
отрицательный контроль, который прошёл — редкий случай, когда аудит заканчивается в пользу кода.

## 4. Что остаётся: мёртвая зона и постоянная составляющая по тикеру

**Мёртвая зона.** В пилоте (`dead_zone: 0.0`, 59 событий) средний `score` = −0.033, медиана
+0.017, диапазон [−0.961, +0.922], и:

- \|score\| < 0.05 у **22.0 %** событий;
- \|score\| < 0.10 у **33.9 %** событий.

Знак `p_pos − p_neg = 0.011` — это разница двух чисел, каждое из которых оценивается с шумом
порядка сотых. В 22 % случаев ставка открывается в направлении, которое не отличается от нуля.
Отсюда прямое следствие: **эффект на 59 событиях разбавлен на пятую часть чистым шумом знака**.
Тест, который это подтверждает или убивает: повторить прогон с `dead_zone: 0.05` (и 0.10).
Если средний эффект растёт сильнее, чем падает n, признак несёт информацию; если MDE растёт
пропорционально — нет. Конфигурация заморожена, поэтому это отдельный прогон, а не правка
`configs/intraday.yaml` на месте.

**Постоянная составляющая по тикеру.** Средний `p_pos − p_neg` по 38 тикерам у FinBERT:
от **−0.0709 (WFC)** до **+0.1970 (PFE)**, sd 0.0591. Разброс 0.27 при среднем по корпусу +0.024
означает, что тон статьи наполовину предсказуем по тикеру, а не по тексту. В кросс-секционной
модели это поглощается фиксированным эффектом; в событийной ветке — нет, потому что знак
`direction` берётся из абсолютного уровня. Проверка: demean `score` внутри тикера и повторить
прогон. Если средний эффект и IC меняются материально, признак работает как дамми тикера.

На подвыборке возмущения (200 заголовков) средние по тикерам тоже расходятся: ABBV +0.299,
MRK +0.195, NVDA +0.079, TSLA +0.065, AAPL −0.014, BA −0.061. Устойчиво только то, что разброс
между тикерами сравним с самим сигналом.

## 5. Три механические причины «нет эффекта», по рангу

| # | Причина | Чем подтвердить / убить | Текущий статус |
|---|---|---|---|
| 1 | Знак берётся из разницы двух шумных вероятностей: 22 % событий имеют \|score\| < 0.05 | Прогон с `dead_zone` 0.05 и 0.10: растёт ли mean быстрее MDE | Не проверено, конфиг заморожен |
| 2 | Постоянная составляющая по тикеру (sd 0.059, размах 0.27) сравнима с сигналом | Demean `score` внутри тикера и повторный прогон | Не проверено |
| 3 | Калибровка на предложениях не переносится на заголовки (neutral 72.9 % → 51 %, крайние классы 36 %) | ECE на 500 вручную размеченных заголовках — единственный тест, который связывает | Не проверено, нужна разметка |

Отдельно: гипотеза «модель смотрит на бренд» проверена и **отвергнута** (§3). Её больше не
нужно упоминать как объяснение.

## 6. Что нельзя утверждать

1. «FinBERT плохо работает на заголовках» — измерения этого не показывают: perturbation-тест
   чистый, корреляция 0.975. Плохо обстоит дело с *разрешением* около нуля, а не с направлением.
2. «macro-F1 0.8862 подтверждает качество на новостях» — нет: 210 предложений, 23 положительных
   примера, другой домен.
3. «open-jev/open-jev лучше/хуже по смыслу» — калибровка на 25 примерах ничего не измеряет.
4. «22 % мёртвой зоны объясняют нулевой результат» — это гипотеза с конкретным тестом (§5), а не
   вывод: она объясняет разбавление, но не отсутствие эффекта.
