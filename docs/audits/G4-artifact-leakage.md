## Проверено чисто

* `y` = `log(adj_close[t+1]/adj_close[t])` из `data/cache/prices_*.parquet` — точно, 49 955/49 955 строк,
  `max |diff| = 9.6e-16`; это не доходность того же дня (Spearman с прошлой `ret_1` = −0.022).
* `ret_1` = `log(adj_close[t]/adj_close[t−1])` на всех 49 955 размеченных строках, `max |diff| = 0`.
* `y_1d == y`; `y_5d` = сумма `y[t..t+4]` (`max 4.9e-16`); `y_dir` = знак `y` на 99.27 % (остальное `y=NaN`).
* `y_used_demeaned` = per-date медианный demean по 50-тикерному кэшу, точно (`max 1.5e-15`), без
  смешивания дат.
* Нет дублей `(ticker,date)`; сплиты непрерывны: train 2019-01-02…2021-12-31, valid 2022,
  test 2023-01-03…2023-12-29, 40 тикеров, 50 320 строк.
* 167 ghost-строк целиком внутри хвостовой логики `label_ok=False`; `label_ok=False` = 365 строк (только хвост).

  сортировка по `|future| − |own|`.
