# Новости → цена: два исследования, один ответ

Репозиторий — это полная, заранее зафиксированная попытка ответить на один вопрос: **можно ли
зарабатывать на публичных новостях?** Вопрос задан дважды — на акциях США и на криптовалютах — и
оба раза ответ измерен, а не предположен.

**Ответ: нет, не при таких издержках.** Из четырнадцати проверенных идей двенадцать закрылись
отрицательным результатом после издержек, одна (внутридневная ветка на акциях) оказалась **не
измеримой** на имеющихся данных, и только одна — макропечать CPI на горизонте 60 минут — дала первую
положительную ячейку за весь проект и осталась **кандидатом, а не стратегией**.

Отрицательный результат и есть результат. Каждое число в этом файле прочитано из артефакта в
`results/`, и два независимых проверяющих пересчитывают их своей арифметикой: `ops/crypto_verify.py`
(78 проверок, 78 совпадений) и `ops/crypto_verify2.py` (перекрытия, бутстрэп, фандинг,
проскальзывание).

## Единственный кандидат и почему это не стратегия

Макропечать CPI — единственное семейство, у которого время публикуется за месяцы, поэтому здесь нет
гонки за заголовком. Вход по направлению релизной свечи через минуту и выход через 60 минут даёт
**+28.65 бп на BTC (t +2.66, net +14.65 после 14 бп)** и **+35.32 бп на ETH (t +2.48, net +21.32)**.

Кандидатом, а не стратегией, она остаётся по пяти измеренным причинам:

1. **Проверено 36 ячеек**; порог Бонферрони \|t\| ≈ 3.2, а лучший результат 2.66. Бутстрэп по дням
   релиза даёт p 0.0068 / 0.0114 → семейная ошибка ≈ 0.24.
2. **Одна эпоха.** 2017–2020: −0.47 (t −0.03); **2021–2023: +72.15 (t +3.14)**; 2024–2026: +16.49
   (t +1.31). Эффект живёт там, где CPI был главным событием рынка.
3. **Латентность.** +28.65 / +20.81 / +11.02 бп при входе через 1 / 5 / 15 минут. Пятнадцать минут —
   уже ниже издержек, а медиана обнаружения живым рекордером 15.9 минуты.
4. **Это не два инструмента.** BTC и ETH коррелированы на r ≈ 0.59 и совпадают по знаку в 68.8 %
   случаев — согласованность, а не независимая репликация. Эффективное n ≈ 108.
5. **Вперёд не проверялось.** Всё остальное в проекте историческое; это единственная гипотеза,
   которую ещё можно опровергнуть новыми данными. Заранее заданное правило: 12 релизов, та же схема,
   14 бп; эффект должен дать net > 0 и t > 1.5, иначе идея закрывается.

При 12 сделках в год 14.65 бп — это ≈ 176 бп ≈ 1.8 % годовых до первого плохого принта, а
абсолютный ход за 60 минут в день CPI — 74.5 бп, то есть один сюрприз стирает год. Плечо запрещено
хвостом, а не вкусом.

## Воспроизведение

```bash
python -m venv .venv && .venv/Scripts/pip install -e ".[dev]"

# акции
python -m spp.cli fetch prices          # 62 900 строк, 50 тикеров
python -m spp.cli fetch news            # parquet-зеркало FNSPID → 124 571 статья
python -m spp.cli score corpus --backend finbert
python -m spp.cli features build --check-leakage
python -m spp.cli train gbdt            # purged CV → reports/runs/<id>/
python -m spp.cli --config configs/final.yaml train test2023   # откажет при повторе
python -m spp.cli backtest --predictions reports/test_2023_predictions.parquet --include-test

# крипта
python ops/crypto_build_bars.py         # 12 мейджоров × 47 месяцев минутных баров
python ops/crypto_macro_bars.py         # BTC/ETH с 2017-08
python ops/crypto_wayback.py --start 2023-01-01 --end 2026-11-09
python ops/crypto_dataset.py            # события + проверки утечек
python ops/crypto_train.py && python ops/crypto_sources.py && python ops/crypto_audit.py
python ops/crypto_btc.py && python ops/crypto_ladder.py && python ops/crypto_classic.py
python ops/crypto_maker.py && python ops/crypto_structural.py
python ops/crypto_listings.py --workers 12 && python ops/crypto_listing_perp.py --workers 10
python ops/crypto_macro.py

# независимые проверки (не импортируют модули пайплайна)
python ops/crypto_verify.py
python ops/crypto_verify2.py
```

Тесты: `pytest -q` → **422 passed, 2 skipped**; `ruff check src tests ops` → чисто.

## Какие данные в git, а какие нет

Сырые минутные бары (~1 ГБ) в git **не лежат** и пересобираются `ops/crypto_build_bars.py` и
`ops/crypto_macro_bars.py`. Производные датасеты **закоммичены** — `data/crypto/dataset/` (21 588
кросс-секционных событий, 24 037 по BTC, 45 625 структурных) и `data/crypto/listings/` (714 спот,
923 перпа), — поэтому каждое опубликованное число пересчитывается без скачивания гигабайта баров.
Подробности: [data/crypto/README.md](data/crypto/README.md).

## Что по дороге было сломано (и исправлено)

Аудит нашёл девять дефектов, и каждый из них смещал результат **в сторону оптимизма**:

| № | дефект | эффект исправления |
|---|---|---|
| 1 | комиссия за одну ногу вместо двух | net завышен ровно на 14 бп на сделку |
| 2 | `legs=2` не доходил до таблицы политики | те же 14 бп, молча |
| 3 | вход в аукцион листинга | фиктивные +337 % среднего стали −2.65 % за час |
| 4 | признаки на BTC пустые в скриптах лестницы | 4 из 15 признаков были мертвы |
| 5 | «банкротства» на 48 % из обзоров ликвидаций | +12.40 (t 2.14) → +13.48 (t 1.63): значимость исчезла |
| 6 | ETF: одобрение проверялось раньше отказа | 13 заголовков с обратным знаком |
| 7 | захардкоженный вывод «единственная положительная ячейка» | вывод считается из данных |
| 8 | подпись горизонта в таблице источников: 5 мин вместо 15 | подпись исправлена |
| 9 | MDE опубликован без кластеризации | 0.41/1.29 → 0.47/1.76 с оговоркой |

В акциях дефекты были той же природы и так же важны: доли сентимента были NaN вместо 0 в дни, когда
новости есть, а статьи нужного уровня нет, и `sector_ret_1` была целиком пуста. После починки CV IC
упал с 0.0202 до 0.0156, а интервал накрыл ноль. Примерно треть первоначального «эджа» была
артефактом пропусков.

## Ограничения

* **Market impact** не моделируется: предполагается, что сделка не двигает цену.
* **Пересечение позиций** не моделируется: события могут требовать капитал одновременно,
  портфельного учёта нет.
* **Фандинг** измерен только для перп-листингов и только за первые сутки.
* **Источники новостей** — 6 архивных изданий; GDELT и часть фидов были недоступны, корпус смещён к
  CoinDesk.
* **Классификатор структурных событий** — по ключевым словам, без ручной разметки precision/recall.
* **Эффект CPI** живёт в одной эпохе и вперёд не проверялся.
* **Holdout на 465 событий** не тронут, но маломощен: его MDE — десятки базисных пунктов.
* **Латентность**: живой RSS-рекордер дал p50 15.9 минуты, а бэктест предполагает 1.45 — это
  оптимистичное допущение, и оно работает против стратегии, а не в её пользу.
